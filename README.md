# Clover Hotel Booking System

A full-stack hotel booking and reservation platform developed for THE CLOVERS GROUP. The application provides an end-to-end booking experience including room selection, guest information management, online payment processing, and booking confirmation.

## Features
- Responsive hotel website design
- Room listing and reservation workflow
- Dynamic booking summary calculation
- Razorpay payment gateway integration
- Booking confirmation and receipt generation
- Local storage-based state management

## Tech Stack
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)
- Node.js
- Express.js
- Razorpay API
